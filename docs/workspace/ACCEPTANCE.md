# Initial Chat preview acceptance

Implemented: Tinode engine/client integration, One Workspace theme and SVG icon,
OIDC state/nonce/PKCE validation, issuer/subject identity mapping, short-lived
single-use engine tickets, session-protected transport/files, private PostgreSQL
supervision, managed catalog/storage/navigation/logout/update integration.

Build and packaging evidence will be recorded when completed. No automated tests
were requested for this feature and none are added/run by default.

Pending before production: fresh Windows install/reboot/service, two-user browser
messaging and discovery, groups and permissions, upload/download access control,
reconnection, logout/expiry, backup/restore, disabled-user/session lifecycle review,
mobile/native client support and full dependency/security acceptance. Calls/TURN,
SFU and external push notification hosting are not configured.
